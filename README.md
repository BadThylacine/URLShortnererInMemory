# URL Shortener

A small URL shortener built as a home assignment. It provides a Thymeleaf-rendered web form, a REST API, and HTTP redirects when a short link is visited.

---

## Functional Requirements

- Users can submit a long URL and receive a shortened version.
- Users can visit a short URL and be redirected to the original.

Optional (not yet implemented):
- Custom aliases, for example `localhost:8080/my-alias`
- Expiration dates for short URLs
- User authentication and resource management

## Non-Functional Requirements

- Each short code maps to exactly one long URL.
- Redirects complete with minimal delay.

Optional with a persistent database:
- Long-term data durability

---

## Prerequisites

- Java 21+
- Maven 3.8+

## Running the Application

```bash
mvn spring-boot:run
```

Open [http://localhost:8080](http://localhost:8080), enter a URL such as `https://example.com/page`, and submit.
The shortened link is rendered on the page. Click it, or open it in a new tab, to be redirected.

---

## API

### Shorten a URL

```http
POST /api/shorten
Content-Type: application/json

{ "url": "https://example.com/page" }
```

Response `200`:

```json
{ "shortUrl": "http://localhost:8080/aB3x" }
```

Response `400` is returned when the URL is missing, malformed, or uses a non-http/https scheme:

```json
{ "message": "Invalid input" }
```

### Redirect

```http
GET /{code}
```

Returns `302 Found` with a `Location` header pointing to the original URL.
Returns `404` if the code is unknown, invalid, or does not match the 4-character format.

## Configuration

`src/main/resources/application.properties`:

| Property | Default | Description |
|----------|---------|-------------|
| `server.port` | `8080` | HTTP port |
| `app.base-url` | `http://localhost:8080` | Prefix used when building short URLs |

When deploying behind a proxy or on a public host, set `app.base-url` to the public address, for example `https://short.example.com`.

## Project Structure

```text
src/
  app/
    UrlShortenerApplication.java   # Spring Boot entry point
  controller/
    PageController.java            # Thymeleaf page for the web UI
    UrlShortenerController.java    # REST API (/api/shorten)
    RedirectController.java        # Short-link redirects (GET /{code})
    ShortenRequest.java            # Request DTO for shortening
    ShortenResponse.java           # Response DTO for shortened URL
    ErrorResponse.java             # Error response DTO
  service/
    UrlShortenerService.java       # Shortening logic and in-memory store
  main/resources/
    application.properties
    templates/index.html           # Thymeleaf UI
```

## Technical Decisions

- Spring Boot + Thymeleaf: embedded server, server-side rendering, REST, and dependency injection in one stack.
- Counter-based code generation: short codes are generated by encoding a monotonically incrementing `AtomicLong` counter into a Base-66 alphabet. This guarantees uniqueness without collision retries.
- RFC 3986 safe character set: the alphabet uses only unreserved characters, so codes do not require percent-encoding.
- http/https-only input validation: `isValidUrl` rejects unsafe or unsupported schemes such as `javascript:`, `file:`, and `data:`.
- `ConcurrentHashMap` for thread safety: the in-memory store is safe for concurrent reads and writes.
- In-memory storage: data is lost on restart, but the API and UI contract can stay the same when replacing the store with a database.
- Separate controllers: `PageController` handles the Thymeleaf UI, `UrlShortenerController` handles JSON endpoints, and `RedirectController` handles redirects.
- Redirect validation: only exact 4-character path segments composed of allowed characters are treated as short codes.
